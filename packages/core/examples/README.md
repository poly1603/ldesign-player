## 📖 功能说明

### 1. 断点续播
- 自动保存播放位置（10秒后开始记录）
- 下次打开自动询问是否继续
- 支持手动清除断点

**使用场景：**
- 长视频分段观看
- 学习视频断点记忆
- 电视剧续播

### 2. 播放速度记忆
- 记住每个视频的播放速度
- 支持 0.5x ~ 2.0x 速度
- 自动应用上次设置的速度

**使用场景：**
- 学习视频 1.5x 倍速
- 有声书 1.25x 倍速
- 音乐保持 1.0x

### 3. 画质切换
- 支持多清晰度（480p/720p/1080p/4K）
- 自动根据网速选择最佳画质
- 切换时保持播放位置

**使用场景：**
- 网速慢时降低画质
- 大屏幕使用高清
- 节省流量

### 4. 手势控制
- **双击**：暂停/播放
- **左右滑动**：快进/快退
- **上下滑动（左侧）**：调整亮度
- **上下滑动（右侧）**：调整音量

**使用场景：**
- 移动端观看
- 触摸屏设备
- 更便捷的操作

### 5. 迷你播放器
- 浮动小窗口播放
- 支持拖拽移动
- 可调整大小
- 自动吸附边缘

**使用场景：**
- 边看视频边工作
- 多任务处理
- 页面滚动保持播放

### 6. A-B 循环
- 设置循环区间
- 自动重复播放
- 统计循环次数

**使用场景：**
- 语言学习
- 音乐练习
- 精听训练

### 7. 播放统计
- 记录播放次数
- 统计播放时长
- 最常播放分析

**使用场景：**
- 用户行为分析
- 观看习惯统计
- 内容推荐基础

### 8. 离线缓存
- 缓存视频到本地
- 支持离线播放
- 显示缓存进度

**使用场景：**
- PWA 应用
- 节省流量
- 无网络环境播放

## 💡 使用技巧

### 测试断点续播
1. 播放视频10秒以上
2. 刷新页面
3. 点击"恢复播放位置"按钮

### 测试手势控制
1. 在移动设备上打开
2. 点击"启用手势"
3. 在播放器上滑动试试

### 测试 A-B 循环
1. 播放视频到某个位置
2. 点击"设置 A 点"
3. 继续播放一段时间
4. 点击"设置 B 点"
5. 点击"启用循环"

## 🐛 常见问题

### Q1: 视频无法播放？
**A:** 检查视频地址是否正确，或尝试使用本地视频文件。

### Q2: 手势控制不生效？
**A:** 确保在移动设备或开启了设备模拟模式。

### Q3: 断点没有保存？
**A:** 确保播放时间超过10秒，且不在最后10秒。

### Q4: 刷新后设置丢失？
**A:** 检查浏览器是否允许 localStorage，某些隐私模式会禁用。
